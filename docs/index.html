GETELEC

General Tool for Electron Emission Calculations

Usage guide Source on GitHub Application for Windows

What GETELEC does

GETELEC calculates electron emission from metallic and semiconducting emitters: the current density, the Nottingham heat and the total and normal energy distributions. It covers field emission, thermionic emission and the thermal-field regime between them, where neither limiting formula works.

The transmission through the surface barrier is obtained by solving the one-dimensional Schrödinger equation with Noumerov's method, for a planar barrier, a sharp tip, a triangular barrier or a potential of your own. GETELEC is a Python package, getelec, and an application for Windows that needs no Python, which also fits measured I-V, I-T and energy-distribution data.

Install and run

pip install getelec
import getelec

getelec.current_density(field=5.0)   # A/cm^2
getelec.nottingham_heat(field=5.0)   # W/cm^2

Fields in V/nm, energies in eV, temperatures in K.

Without Python: download GETELEC-windows.zip, extract it and double-click GETELEC.exe. Step-by-step instructions for both are in INSTALL.md.
